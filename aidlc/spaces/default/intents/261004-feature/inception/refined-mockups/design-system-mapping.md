# OMS 시각 기준과 디자인 시스템 연결

## 결정 범위

Q2의 밝은 중립색·절제된 강조색과 고객/직원의 밀도 차이를 적용한다. 기존 브랜드/디자인 시스템은 없다. 아래 토큰은 첫 화면 설계 제안이며 상표·브랜드 정식 명칭이나 UI 라이브러리/기술 스택 선택이 아니다. HTML 미리보기는 외부 폰트·이미지·분석 스크립트 없이 로컬 파일로 동작한다.

## 색상 수치 검증

고정 토큰 쌍의 sRGB 상대 휘도 계산 결과다. 실제 합성/투명도·hover·focus·disabled·차트·브라우저 렌더링 및 전체 적합성은 별도 검증이 필요하다. 보통 텍스트는 4.5:1, 적용 가능한 필수 조작/상태의 비텍스트 구분은 3:1 기준으로 검사한다. 대형 텍스트/비활성 등 예외는 해당 W3C 기준에 따라 판단하며 일괄 면제하지 않는다.

## PC 레이아웃·정보 밀도

| 구역 | 고객 | 내부 직원 |
|---|---|---|
| 공통 셸 | 216px 탐색 + minmax(0,1fr) 본문, 문맥/한 h1 | 동일 골격, 별도 직원 문맥과 허용 업무 |
| 본문 1280 | 외곽32, 영역24, 표 기본 행56 | 외곽24–32, 영역16–24, 표 기본 행44–48 |
| 상세 | 요약/다음 행동 우선, 상세·이력은 이어서 | 근거·대상 버전·판단·결과를 나란히 검토 가능 |
| 1440 이상 | 본문 최대1280 범위에서 읽기 폭 제한, 긴 표는 내용에 맞게 | 표·근거 2열을 확대하되 동일 정보/읽기 순서 유지 |
| PC 창 축소/확대 | 탐색 → 본문, 2열 → 단일 열, 라벨/값 줄바꿈 | 동일 접근성 재배치. 직원 모바일 제품 화면으로 해석하지 않음 |
| 표 | 의미 유지 가능한 것은 항목 제목/값 재배치 | 비교에 2차원이 꼭 필요한 표는 표 영역만 스크롤, 나머지 페이지 양방향 스크롤 방지 |

1280은 기본 PC 지원 범위다. 고객 모바일 지원 여부는 유보이며 360/768 모바일 레이아웃·모바일 기능 검증을 첫 제품 확정 의무로 두지 않는다. PC 확대/리플로우는 유지한다. WCAG 리플로우 조건의 320 CSS px 상당 검사는 PC 확대의 검증이며 모바일 제품 지원 확약이 아니다. 실제 콘텐츠에 맞춰 줄바꿈 지점을 조정하되 정보/동작을 제거하지 않는다.

## 내용·표기 원칙

- 한국어 화면, KRW 금액은 원 단위를 표시한다. 업무 시각은 한국 시간임을 명시한다. 향후 영어(미국) 방향을 위해 문구와 의미를 분리할 수 있게 설계하되 USD·미국 시장/시간대 지원을 추가하지 않는다.
- 같은 상태는 같은 문구, 미확인은 미확인으로 표시한다. 주문 확정과 지급/상품 제공/갱신 완료는 별도다. 계약·실제 기간, 요청·승인·실제 적용을 서로 다른 제목으로 표시한다.
- 버튼은 실제 단계의 동사를 쓴다: 요청 제출, 승인, 결과 재확인, 실패 잔량 재처리. 신청/승인만 하는 행동에 완료/지급 완료/사용 시작 문구를 사용하지 않는다.
- 원래 값/출처와 변경 근거를 보존한다. 이메일은 최소 안내+로그인 링크이며 라이선스 키·민감 계약 내용을 넣지 않는다.
- 합성 데이터와 상태 선택 도구는 제품 UI 밖의 미리보기 구역에만 표시한다. FR/US/AC/OQ·API/클라우드 설정은 실제 고객 업무 화면에 노출하지 않는다.

## 비교·역할 편집의 배치

- C04/C05 가격 변경 제안은 대상/내용 버전·회차를 먼저 표시하고 원래/변경 조건을 같은 비교 표에서 읽는다. 주요 행동은 ‘제안에 동의’, 보조 행동은 ‘제안 거절’. 미확인·내용 변경은 상태 문구와 현재 제안 재확인으로 표현한다.
- C07은 대상/업무 선택 → 라벨 있는 소속·활성/관리자 입력 → 전후 검토 → 결과/이력의 단일 읽기 순서를 유지한다. 관리자0명 경고는 색상 외 제목·본문으로 표시한다.
- C08은 이름/역할 선택 →15개 행위 fieldset → 행위별 범위 → 최종 검토 → 별도 사용자 부여/회수 구역이다. 1280 PC에서 fieldset2열, 좁은 PC/확대에서1열로 배치한다. 범위 추가/삭제는 드래그 없이 명시적 버튼이며 조작 후 같은 행위의 입력/버튼으로 초점을 복귀한다.
- 지급·발급의 미부여 사실을 색상 배지나 요약/이력으로 남기지 않는다. 모든 재사용 컴포넌트에 같은 필드 권한을 적용하고 허용된 주문 정보·복귀 경로를 유지한다.

## Assumptions & Open Questions

- [assumption] 토큰·밀도가 고객/직원 업무와 한글 읽기에 적합하다. 실제 브랜드 승인·사용성 시험은 별도다.
- 고정 색상 대비 계산은 부분 근거다. 모든 상태/브라우저·키보드·보조기술·확대·동적 내용의 검증 전 AA 적합성을 주장하지 않는다.
- Q5 고객 모바일 유보가 최신 기준이다. 기존 NFR12·AC1.3.4·AC3.1.4의 모바일 지원 문구를 그대로 구현 의무로 적용하지 않는다. 업무·권한 결과는 유지한다.
- 입력 상한·날짜 포함 경계·긴 기업명/상품명·첨부 근거 형식·세션·실제 브라우저 폰트 차이는 관련 OQ 및 기능/NFR 설계에서 구체화한다.
