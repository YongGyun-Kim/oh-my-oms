# OMS 제약 등록부

작성일: 2026-10-05. 상태: 사용자 검토용.

## 읽는 방법

확정은 사용자 답변에 근거한 조건, 미정은 결정 전인 항목, 미확인은 정보가 없는 항목이다. 위험 검토 항목을 확정된 제품 요구사항으로 해석하지 않는다. C03은 제약이 아닌 사용자 확정 설계 목표이며, 추적 ID를 유지하기 위해 이 등록부에 함께 둔다. 담당은 기존 인원 사실과 별개인 **확인 담당 제안**이며 사용자·개발자에게 아직 업무가 배정된 것은 아니다.

## 지금 확정하지 않는 수치와 구조

출시 날짜, 월 비용, 처리량, 가용성, 응답 시간, 허용 데이터 손실·복구 시간, 운영 인력 추가 여부를 임의로 정하지 않는다. 서버·DB·큐·배포 단위·고객 데이터 분리 방식 등 구체적 구성도 미정이다. AWS·CDK 결정은 사용자의 명시적 제약으로만 반영한다.

## 변경과 추적

사용자 결정이 추가되면 해당 ID의 상태와 근거를 갱신한다. C05의 자료 부재는 공개 문서 추가만으로 해소되지 않는다. C06·C07의 도구 선택과 C08의 준비 상태는 별도로 확인한다. 위험·가정·현재 이슈·외부 의존은 [RAID](raid-log.md), 전체 판정과 V1–V6 검증 제안은 [평가서](feasibility-assessment.md)를 참조한다.
