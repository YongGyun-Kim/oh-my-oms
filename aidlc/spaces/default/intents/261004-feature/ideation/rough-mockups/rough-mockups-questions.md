## 화면 구성 제안과 미확인 사항

아래는 승인된 scope-document의 SC-01–SC-10 및 이번 Q1–Q4를 화면으로 표현하는 작성 제안이다. Q4의 최신 지시가 내부 직원의 기기·접근 조건에 관한 Q1의 이전 선택을 대체한다. 별도 기능이나 확정 업무 정책을 추가하지 않는다.

- 고객 화면 묶음: 주문·갱신 현황, 상품 확인, 상품 타입별 주문 요청·제출 결과, 주문 상세·청구/지급/이행 진행, 권한·기간·갱신, 변경·취소·반품 요청과 처리 결과.
- 내부 직원 화면 묶음: 처리할 업무 목록, 권한 내 일반·완료 주문 목록과 상세, 상품 등록·관리, 주문 확인·상세와 청구·지급 상태, 하드웨어 확보·출고/배송 진행, 소프트웨어 발급·기간/갱신 진행, 변경·예외·회수/환불 결과 확인.
- 화면 명칭·묶음은 검토용이며 실제 페이지 수나 메뉴 구조는 초안에서 제안한다. 화면 배치가 API·서비스·배포 구조를 결정하지 않는다.
- 접근성 작성 기준 제안: 제목·영역·키보드 진입점, 명시적인 입력 라벨, 색상에만 의존하지 않는 상태, 오류와 복구 경로를 화면별로 설명한다. 사용자 고유의 추가 접근성·보조기기 요구는 현재 미확인이다. 특정 법규 적용이나 접근성 인증 통과를 주장하지 않는다.
- 미정 정책: scope-document OQ-01–OQ-10을 유지한다. 자동 확정 조건, 가입/로그인 방식, 갱신·대금·취소 허용 조건, 실제 권한 전달 방식 등은 예시 화면만으로 확정하지 않는다. 조작의 의도와 처리 결과를 분리해 보여 준다.
- 화면 예시 데이터는 가상이며 실제 고객·실거래·시장 검증 자료가 아니다.
